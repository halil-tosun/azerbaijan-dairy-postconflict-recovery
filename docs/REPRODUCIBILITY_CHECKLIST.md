## Known, Documented Analytical Corrections

Three substantive corrections were made to this study's code and/or
manuscript text during preparation, prior to this package's release,
and are disclosed here in full for transparency.

**1. DEA bootstrap degenerate-replicate bug.** For district-years whose
raw VRS score is exactly on the frontier (θ̂ᵢ=1), the smoothed-reflection
bootstrap could, for a subset of the B=200 replicates, return a
numerically "successful" but degenerate solution (observed: an
unbounded-variable ceiling value) rather than fail explicitly. Left
unfiltered, this either silently dropped affected district-years (NaN)
or corrupted their bias-correction mean, producing an unexplained
off-by-a-few discrepancy between reported and reproduced N in several
early-draft tables. Fixed by adding a `DEGENERATE_THETA_CEILING=5`
filter with a raw-score fallback for the rare case where all 200
replicates are degenerate (see `docs/CODEBOOK.md`, "Boundary-Case
Bootstrap Replicates"). This is a code fix; the corrected code is the
only version in this package.

**2. Second-stage sample-construction merge bug.** An earlier version of
`build_second_stage_sample()` in `03_second_stage.py` attempted to merge
in `cost_milk`/`profitability` columns that were already present in the
DEA-bootstrap output, causing a pandas column-name collision that
silently defeated the `outlier_treatment` argument and, on newer pandas
versions, raised a `KeyError` that broke the one-command `run_all.py`
workflow entirely. Fixed by dropping the pre-existing columns before
merging. This is a code fix; the corrected code is the only version in
this package.

**3. Manuscript transcription error, Table 3.** An early manuscript
draft reported the translog SFA's ln(cattle stock) coefficient as
14.126; the underlying code output was always correct (1.4126) --
only a decimal point had been mistyped in the manuscript text during
drafting. Caught by cross-checking the manuscript against this
package's own `output/` files prior to release. This was a manuscript
text error only; no code was affected.

No other discrepancies, corrections, or known numerical differences
between this package and the manuscript were identified.

## A Note on Interpretation, Not Correction: The Control-Frontier Causal Estimate

Unlike the three items above, the following is not a bug or an error --
it is the study's central, intended finding, and is documented here so
that a reader auditing this package for "problems" does not mistake it
for one. The manuscript's primary causal-evaluation specification
(Table 6, control-frontier, district-clustered SE) produces a
**larger** point estimate (+0.1156) than the secondary pooled-frontier
specification (+0.0567), but a **weaker** statistical result (p=0.300
vs. p=0.087) once standard errors are clustered at the district level.
This is not a contradiction and not an error in either script: it
reflects the combined, and independently verified, effect of (a)
removing a source of mechanical interference that biased the pooled
estimate's precision, and (b) correcting standard errors that had
previously been computed under a classical (homoskedastic,
non-clustered) assumption inappropriate for this panel design. See the
manuscript's Discussion (Section 4.4) for the full methodological
argument, and SI Tables S17-S18 for the additional diagnostics
(control-frontier truncation behavior, Aghdara-exclusion sensitivity,
wild cluster bootstrap) that were run specifically to stress-test this
finding before it was finalized.
